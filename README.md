# Watchletic skill

A portable AI skill for analyzing and safely managing a Watchletic Club member's cloud data through the official `watchletic` CLI.

The canonical repository is [watchletic/skill](https://github.com/watchletic/skill). This repository is independent from the CLI. Install or link it using the skill mechanism supported by your agent. A future CLI command may install a pinned GitHub release.

The skill keeps AI inference agent-side, starts from bounded deterministic summaries, and requires explicit confirmation before mutations.
