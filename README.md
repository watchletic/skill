# Watchletic skill

A portable AI skill for analyzing and safely managing a Premium user's Watchletic cloud data through the official `watchletic` CLI.

This repository is independent from the CLI. For local testing, install or link this directory using the skill mechanism supported by your agent. A future CLI command may install a pinned GitHub release after the Watchletic organization exists; this repository currently has no remote and is not published.

The skill keeps AI inference agent-side, starts from bounded deterministic summaries, and requires explicit confirmation before mutations.
